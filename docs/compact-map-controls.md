# 地圖控制與裝置圖卡精簡

- 主畫面2D的崩塌圖資改為與地形並列的勾選項，預設不顯示選單；裝置詳情的地圖標題旁也提供同一開關。
- 關閉開關會隱藏選單、兩個圖層及範圍彈窗；重開保留個別圖層選擇。非同步載入完成後仍遵守外層開關狀態。
- 選單標題簡化為「崩塌圖資」，移除「靜態潛勢 ≠ 即時警戒」；官方來源與圖資年度保留在點選範圍後的彈窗及裝置比對摘要。
- 裝置資訊卡保留六項數值，改為三欄兩列；座標與定位時間集中。GPS不再占用整列，以勾號/叉號/驚嘆號定位圖示呈現：綠色有效、紅色無效、黃色定位超過10分鐘、灰色未提供。圖示提供title與aria-label。
- GPS狀態以裝置回報旗標與最後有效定位時間判斷；座標仍保留六位小數。最後更新與定位時間不混用。

驗證：npm run check（0錯誤0警告）、npm run build成功。以本機合成資料視覺預覽，有效、無效、過期GPS與長名稱皆可完整顯示，一般圖卡約261px，長名稱加詳情按鈕約322px，低於460px地圖高度。視覺預覽工具不納入正式部署。
