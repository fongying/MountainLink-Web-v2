# AI 設定頁模型測試

管理者在 `/settings` 選好 Lab 位址、模型與 CPU 相容模式後，可直接按「測試模型」，不必先儲存。

- 使用目前選項呼叫 `/api/generate`，傳送固定簡短 JSON 問題，不帶入裝置位置或生理資料，也不廣播 Meshtastic 訊息。
- 短測試使用 context 4096、batch 64、輸出上限 512、溫度 0.1 與目前 CPU 開關；完整分析使用較高的 context 與輸出額度；每次最長 90 秒。
- 成功必須收到完成旗標及可解析的 JSON `ok: true`；只取得模型清單、HTTP 200、尚在思考或不符 JSON 均不能視為通過。
- 結果顯示模型、執行模式、耗時、回覆與可用時的輸出速度；分別提示 HTTP/runner 錯誤、逾時、連線及回覆格式問題。
- 選項改變後會標示上次結果已不適用。測試不會儲存模型、變更 CPU 設定或下載模型。
- 測試與既有儲存、偵測動作一樣要求管理者登入，限制 Lab 主機、拒絕重新導向並先核對模型存在。
- 簡短測試不代表完整 AI 建議已通過；仍需在監控中心執行完整分析。

9 項自動測試涵蓋選定模型/CPU 參數、推論成功、錯誤回覆、非 JSON、錯誤答案、未完成/思考輸出、逾時及網路異常。型別檢查與 VPS 正式建置通過。

正式瀏覽器實測：gemma2:9b、自動硬體模式，0.71 秒回覆有效 JSON，6 tokens、81.4 tokens/s，顯示測試通過。測試沿用當前選項，沒有覆蓋既有設定。
