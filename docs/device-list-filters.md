# 裝置列表分類篩選

修正 `/devices` 上方分類按鈕只能改變卡片樣式、清單卻沒有立即重算的問題。原本 Svelte 反應式清單僅直接依賴 devices，filter/query 被包在函式裡，導致點選分類或輸入搜尋不會立即更新。

現在將 filter 與 query 明確傳入篩選函式，使切換分類、搜尋文字與 SSE 裝置更新都能觸發清單更新。

- 全部：所有裝置；在線／離線：依 online；SOS：依 sos。
- 風險沿用既有生理與低電量條件，沒有變更判定門檻。
- 搜尋與分類取交集；搜尋裝置 ID、名稱、單位與 sender。
- 選取卡片保留高亮並提供 aria-pressed，列表標題顯示目前分類，符合筆數會更新並提供無障礙狀態通知。
- 上方數字仍為全部裝置的分類統計，下方筆數為目前分類加搜尋的結果。

本機與 VPS 型別檢查 0 errors / 0 warnings，正式建置通過。部署前核對原始來源與 Git 分支一致，備份來源、build 與 SQLite 後切換；沒有修改遙測上傳或 AI 流程。

正式瀏覽器驗收：全部 6、在線 3、SOS 3、風險 1、離線 3；離線 + COM5 搜尋為 1 筆，在線 + COM5 為 0 筆，清除搜尋恢復 3 筆。已觀察 SSE 心率更新後仍保留在線分類。
