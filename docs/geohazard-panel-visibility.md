# 崩塌圖資結果的顯示分級

裝置頁不再對所有比對結果常駐顯示黃色警示卡。原始 `assessGeohazards`、GeoJSON、API 回覆與 AI 證據未修改。

- 定位有效但未落入、且最近圖斑距離超過 100 m：只顯示中性的「崩塌圖資詳情 · 未落入本版圖資範圍」，預設收合。
- 落入圖斑或精確位於邊界：顯示醒目的位置提示；仍說明潛勢圖不代表災害已發生。
- 圖斑外且距離 100 m 內：標示「位置需確認」，清楚註明 100 m 是介面提醒距離，不是官方警戒門檻或 GPS 誤差，不更動原始 outside 判定。
- 缺少 GPS 精度本身不觸發警示。無座標、GPS 無效、定位過期或圖資無法使用，保留中性的「暫不判定／無法使用」說明，不宣稱安全或未落入。
- 最近圖斑及其官方屬性僅放在展開詳情，標示「非目前位置風險等級」。例如 98,621 m 以 98.6 km 表示，明確為平面近似距離。
- 裝置或位置更新時先清掉舊結果，避免新位置查詢期間仍看到上一個位置提示；重複輪詢不強制收合使用者已開啟的詳情，切換裝置才重置。

驗證：6 項顯示條件與距離格式測試通過，包含遠距／GPS 精度未知、區域內、邊界、100 m 提醒界線、無效／過期定位與混合結果。Svelte check 0 errors / 0 warnings；正式建置通過。
