# AI裝置資料21天期限

AI分析入口以裝置最後更新時間updatedAt為準，排除滿21天（21×24小時）未更新的紀錄，包含仍標記SOS的舊裝置。排除於風險排序、焦點隊伍選擇、裝置證據及提示詞之前完成，不依賴模型自行忽略。未達21天的離線裝置仍參與風險分析。

時間缺失、非數值、零值或超過現在一分鐘的異常未來時間亦不採作目前證據。資料庫與裝置列表不刪除、不隱藏歷史紀錄。既有AI歷史報告保留，之後的新分析套用此規則。

驗證：tests/ai-device-freshness.test.ts，3項測試涵蓋剛滿21天前後1ms邊界、舊SOS與新SOS/近期離線共存、時間異常以及輸入不被改寫。
