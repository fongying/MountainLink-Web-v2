# 官方大規模崩塌圖資整合

來源：農業部農村發展及水土保持署，政府資料開放授權條款第1版。
- 115年94處潛勢區：https://data.gov.tw/dataset/176527
- 115年94處影響範圍：https://data.gov.tw/dataset/176528

原始 SHP 的 .prj 已確認為 EPSG:3826，經 PROJ 轉為 EPSG:4326。保留原始多邊形（含洞），不公開保全戶地址。GeoJSON metadata 保留來源、抓取時間、原檔 SHA256 與來源座標系統。這次範圍僅為大規模崩塌，未匯入1753條土石流圖資。

## 行為與限制

登入後可在主畫面2D及裝置地圖勾選兩種圖層，點選看官方編號及來源。3D模式未加入此圖層，切回2D即可查看。
裝置詳情每次定位更新及每分鐘重新比對；GPS無效、定位時間超過10分鐘或異常時不以舊位置判定目前風險。MX2使用獨立定位時間；無獨立時間的舊裝置沿用最後更新時間，無法證明座標的實際取得時間。系統未收到水平定位精度，因此邊界附近必須人工確認。距離為局部平面近似邊界距離，不是行走路線距離。

範圍內回傳命中的官方區域；兩類均未命中時各列最近一個範圍與距離，不設定任意危險半徑，也不宣稱安全。潛勢與影響範圍不代表即時警戒或已發生災害。

AI取得精簡比對結果及獨立 geohazard 證據，不傳送全國幾何。原Google高程摘要保留作地形起伏參考，移除以高差直接推論崩塌的說法。既有CWA警示流程保留；本次未新增農村水保署即時崩塌警戒源，也未新增靜態圖資的自動廣播。

## 更新

在專案根目錄，以 Python 安裝 pyshp/pyproj/shapely 後：

    python scripts/geohazards/import_official.py --download

工具只在兩份下載、解析、幾何及94筆數量檢查都通過後，以原子替換更新 GeoJSON。新年度/數量異動應人工審閱並同步修改版本檢查。伺服器依檔案mtime重載，檔案遺失/解析失敗回傳 unavailable，API 503；不能將失敗當作範圍外。
